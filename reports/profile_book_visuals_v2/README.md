# HSS 2025 Profile Book Visual Family v2

Deterministic public-facing SVG and 300-dpi PNG graphics for the Kabupaten Hulu Sungai Selatan Profile Book.

The chart values are rebuilt from the locked 2025 brief and source charts. The map is rendered from the existing authoritative spatial package used by the Diklat PIM application. Unresolved project links are represented only as regional highlights; no new exact road geometry is invented.

See `word_asset_manifest.md` for report placement and `09_qa/contact_sheet.png` for review previews.
